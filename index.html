Como criar arquivos .lrc?

Arquivos .lrc servem para sincronizar a letra com a música. É super simples criar o seu:

  1. Abra o bloco de notas (ou qualquer editor de texto).
  2. Coloque o tempo exato em que a frase é cantada no formato [mm:ss.xx] no início de cada linha.
  3. Exemplo:
    [00:12.30] Hello, how are you?
    [00:15.00] I am fine, thank you.
  4. Ao salvar, escolha "Salvar como...", mude o tipo para "Todos os arquivos" e digite .lrc no final do nome do arquivo (ex: minhamusica.lrc).

Dica TDAH: Existem sites gratuitos como lrcgenerator.com que permitem apertar a barra de espaço para sincronizar tudo automaticamente enquanto você escuta a música!
